# chatIR wordmark v1

Keep the spelling `chatIR`: lowercase chat, uppercase IR, no gap.

- Solid: default in navigation, body text, compact controls, and small artwork.
- Outline: a SEPARATE monochrome sticker/artwork option, with outlined chat + filled IR. Never use outline as the normal web wordmark. Use white on dark or navy on light.
- On dark: chat #edf4fd, IR #6ab2ef. Suitable for #0d1726 and #142b45 backgrounds.
- On light: chat #132a44, IR #216cba. Suitable for white and #f5f8fc backgrounds.
- Other backgrounds: use a tested solid surface behind the mark; do not choose a variant by guesswork. High-contrast mode uses system colors and filled letters.

The four SVGs contain vector paths, not font-dependent text, and have transparent backgrounds. They use DM Sans at weight 650 and optical size 32. OFL.txt contains the font license. In web prose the two spans remain contiguous, selectable text and retain the surrounding size. Display marks use DM Sans. Keep metadata, URLs, legal names, plain-text messages, and code as ordinary text.

SVGs have an accessible name. When embedding as an image, use alt="chatIR" (or empty alt when an adjacent label already supplies the name). Don't change link destinations to style the brand.
